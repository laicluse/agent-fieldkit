Responsive model

One focused pane when space is tight. More context when space is available.

Most responsive layouts handle narrow screens by stacking columns into one long page. That works for editorial content, but data-heavy applications often need a different rhythm: one focused pane on small screens, and as much useful context as possible when there is room.

Supermax is built around that hybrid. On a phone, a layout can behave like an iOS-style navigation stack: move one step deeper, show one cell, and go back when needed. On a wider screen, those same cells sit side by side and grow up to their configured max widths.

The result is a layout engine that protects each pane's single responsibility while using the available screen real estate, from a phone to a 34-inch monitor.

Package

Install the package and let the host render.

Supermax is a framework-free ESM package. Its workspace decides which cells show, fold or move, and animates them; your application renders what goes inside each cell and keeps its own data, routing and persistence.

1. Add it

Pin the public GitHub package until it is published through a registry.

corepack pnpm add github:laicluse/supermax#beaf89b

2. Declare destinations

Each destination is a cell with a title and a minimum and maximum width; one may grow into the space that is left.

import { Navigator } from "@laicluse/supermax";

const navigator = new Navigator({
  root: "inbox",
  minViewportHeight: 360,
  destinations: {
    inbox: { title: "Inbox", min: 240, max: 360 },
    "message:1": { title: "Weekly report", min: 320, max: "*", preferred: 420 },
  },
});

3. Open a workspace

The workspace fills its element and asks your content callback for what goes inside each cell it opens.

import { Workspace } from "@laicluse/supermax";
import "@laicluse/supermax/workspace.css";

const workspace = new Workspace(element, {
  navigator,
  content: (occurrence, definition) => ({ element: renderFor(definition) }),
});

workspace.navigate("message:1", { from: "inbox", origin: null });

Model

One shell that fits open work into a changing viewport.

Chains and rows

A cell opens to the right of the cell it came from. A split gives independent tasks their own rows, each with its own chain, and takes its width from its widest row.

Folds and Show

When room runs out, earlier cells leave the window or fold to a handle. Every open cell keeps a route back: its fold handle, the Show control, or zooming out.

Your content, your look

Supermax never measures or renders your content. A content callback mounts it, a renderer map restyles the shell, and an optional plugin teaches coding agents the contract.

Source

A public source package under l'Aicluse.

The package exports Navigator, Workspace, CellCollection and CellStrip as named ESM exports, with the stylesheet at @laicluse/supermax/workspace.css. The public source, its guides and the migration guide from version 1 live at github.com/laicluse/supermax.
